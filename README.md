# Trabajos — Ramo IA

Repositorio con los notebooks y datos usados en la asignatura de Inteligencia Artificial.

**Objetivo**
- Reunir las tareas, ejercicios y notebooks desarrollados durante el curso.

**Estructura**
- `notebooks/` — Cuadernos Jupyter (.ipynb) organizados por evaluación o tema.
- `data/` — Conjuntos de datos usados por los notebooks.
- `notebooks/README.md` o subcarpetas — documentación específica por práctica (cuando aplique).

Cómo usar
- Instala dependencias (recomendado crear un entorno virtual):

```powershell
python -m venv .venv
.\.venv\\Scripts\\Activate.ps1    # PowerShell
pip install -r requirements.txt   # si existe
```

- Abrir un notebook:

```powershell
jupyter lab    # o jupyter notebook
```

Notas sobre ramas
- En este repositorio se consolidaron archivos desde ramas antiguas a carpetas (`notebooks/` y `data/`).
- Si necesitas restaurar una rama borrada, busca el SHA del commit o contacta al autor.
