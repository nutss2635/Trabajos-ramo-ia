# Trabajos asignatura de Inteligencia Artificial

Repositorio con los notebooks y datos usados en la asignatura de Inteligencia Artificial.

**Objetivo**
- Reunir las tareas, ejercicios y notebooks desarrollados durante el curso.

**Estructura**
- `notebooks/` — Cuadernos Jupyter (.ipynb) organizados por evaluación o tema.
- `data/` — Conjuntos de datos usados por los notebooks.
